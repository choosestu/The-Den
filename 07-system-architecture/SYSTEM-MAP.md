## The Core Framework Decision Filter

Before acting on any new task or idea, run it through in order:

1. Does it advance The One Thing for today, or one of the current top five?
2. Does it move toward Whistler or Kelowna by 2028?
3. Is family protected?
4. Is it lean, or does it bloat the system?
5. Is this a project, or am I searching for enlightenment?

If it fails 1 and 2, route to Idea Bank or drop it.
