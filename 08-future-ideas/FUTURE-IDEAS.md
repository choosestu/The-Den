# Future Ideas
## Concepts not ready for v1 — revisit in Phase 3-5

---

**Automated Voice Capture (Fieldy v2)**
The local Python webhook concept is right but the implementation is fragile. Rebuild in Phase 4 using iOS Shortcuts or a cloud-based transcription service. No local server.

**The Privy Council**
Advisory seat concept (Legal, Finance, Operations, Marketing). Intellectually sound framework for major decisions. Too much friction for daily use. Revisit if the decision log in Phase 2 proves insufficient.

**Morning Briefing Email**
5am automated summary: calendar, top tasks, stale Waiting On items, one question. Build in Phase 4 only after the manual morning ritual is a stable habit.

**Upperview Homes / New Home Sales Platform**
Full digital sales office: ID verification, pricing engine, document automation, Tarion notice triggers. Significant SaaS opportunity. Requires dedicated project folder and separate development track. Not part of The Den.

**S2 / The Foundation Integration**
S2 conversation insights feeding the RTDL automatically. Phase 5. Requires stable Foundation platform and reliable API surface.

**Persistent Memory (no paste-in)**
True cross-session memory without manual Stu.md paste. Depends on tooling availability. Track Claude memory features and Cowork roadmap. Phase 5.

**Veritas / Memory Miner**
The memory extraction concept: take a long conversation or transcript and pull out decisions, promises, facts, and tasks. Useful pattern. Can be done manually with a prompt now. Build as a scheduled automated pass in Phase 4.

**LPT AI Positioning**
Position Stu as the AI-forward agent at LPT. Build small, sharp tools other agents find useful. Recruiting fuel. Start after the personal OS is stable (Phase 2-3).
