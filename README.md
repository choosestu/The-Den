# The Den

**Master repository for Stuart Smith's personal AI operating system.**

This repository consolidates all prior work across ChatGPT, Claude, Lovable, and any other platform under a single organized structure. The goal is not to merge everything blindly. It is to preserve prior work, analyze what actually functioned, and produce a clear path to a stable v1 system.
